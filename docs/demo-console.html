Priority PillarQuestion to Ask the CustomerWhy It Matters / Trap Uncovered
1 · Governance Q1: Do any developers belong to both a regulated org and a general org when policies use "Let organizations decide"? Least restrictive wins for CLI, Cloud Agent, App, and MCP; only 4 sensitive policies use Most restrictive.
1 · Governance Q2: Have you audited policies in Unconfigured state before the 22 October 2026 Default policy for new features cutover? Default policy for new features is enabled by default and auto-enables unconfigured GA features (+ Code Review & MCP).
1 · Governance Q4: Do you assign seats directly at the enterprise level while relying on "Let organizations decide"? Direct enterprise seats ignore "Let organizations decide" and follow Policies for enterprise-assigned users.
1 · Governance Q6: When you disable Copilot can search the web, how are you governing internet egress for Copilot cloud agent and CLI? Copilot can search the web only governs IDEs and GitHub.com Chat—not Cloud Agent (uses agent firewall) or CLI.
2 · Usage & Admin Q12 & Q13: What share of users are in Phase 2/3 agent cohorts vs. Passive (No Cohort), and why are Chat-only users marked Passive? Requires >=2 active days in 28d. Chat without code completions/edits does not qualify for Phase 1.
2 · Usage & Admin Q14 & Q15: Why does summing organization DAUs exceed Enterprise DAU, and why is DAU higher than IDE feature sums? Org attribution follows org membership (not billing org); server-side telemetry counts users whose IDE telemetry is blocked.
2 · Usage & Admin Q19: When a shared Cost Centre budget has headroom, why is a developer still blocked by the $10 enterprise per-user default? Two-rule precedence: 1 non-additive user budget (user > multi_user_cost_center > multi_user_customer), then lowest hard-stop headroom wins.
3 · Security & Audit Q21: Are developers using Copilot CLI or IDE Agent Mode in repos relying on Content Exclusion for secret protection? GitHub Docs explicitly states Copilot CLI and IDE Agent Mode do not support content exclusion; use repo RBAC + Push Protection.
3 · Security & Audit Q23 & Q24: How do you correlate agent PRs (`actor:Copilot`, `agent_session_id`) vs. full prompt/response bodies (`usage-records`)? Audit log tracks control-plane & agent actions (180d); EMU /copilot/usage-records streams full prompt/response JSON payloads.
